# 五看三定：MiniChain 的战略分析

> 华为「五看三定」：看行业/趋势、看市场/客户、看竞争、看自己、看机会，
> 再定战略控制点、定目标、定策略。

## 一、五看

### 1. 看行业 / 趋势

- 区块链正从「加密资产」叙事回归「可信基础设施」：存证、供应链金融、隐私计算成为主战场。
- 开源是该行业的默认协作方式：Bitcoin、Ethereum、Hyperledger Fabric 全部开源，代码即标准。
- 教育侧：区块链工程已成为高校新专业方向，但教学工具仍以「重型框架」为主，
  缺少 10 秒可运行、可逐行讲解的最小实现。

### 2. 看市场 / 客户

- 客户：高校区块链/信息安全课程教师、助教、自学转行的开发者。
- 痛点：Ganache/Fabric 部署重、依赖多、黑盒；网上 demo 多为片段，缺文档、缺许可证、缺测试。
- 规模：长尾但稳定，每年有新一届学生进入，且教师的课件会逐年复用。

### 3. 看竞争

| 竞品 | 优势 | 劣势 |
| --- | --- | --- |
| Ganache / Truffle | 生态成熟、可视化 | 面向 DApp，重，需 Node |
| Hyperledger Fabric samples | 企业级、真实 | 需 Docker，门槛高 |
| GitHub 上的 blockchain demo | 轻 | 缺文档/许可/测试，不可维护 |

差异化：**零依赖 + 中文可解释文档 + 完整开源治理示范**。

### 4. 看自己

- 优势：成本极低（单人一周可完成 MVP）；课程场景真实；代码可读性可控。
- 劣势：无社区、无性能、无安全审计；不具备生产可用性。
- 资源：GitHub 免费托管与 Actions、课程同学作为种子用户。

### 5. 看机会

- 把「一次课程作业」变成「可持续维护的教学工具」：课程每学期都会产生新需求。
- 借开源社区分发：提交到 awesome-blockchain 类清单、在课程群与教师间传播。
- 时间窗口：新学期开课前完成 v1.x，正好被下一届课程采用。

## 二、三定

### 1. 定战略控制点

技术本身没有壁垒（代码可被复制），真正的控制点是：
**「区块链入门第一课」的标准示例 + 高质量中文文档 + 课程渠道关系**。
用 MIT 许可证降低采用门槛，让「被引用」成为事实标准。

### 2. 定目标

| 阶段 | 目标 |
| --- | --- |
| 1 个月 | v1.0 发布：README、文档、测试、许可证齐全 |
| 3 个月 | 30 star、3 个外部 Issue、被 1 门课程列为参考资料 |
| 6 个月 | 100 star、2 位外部贡献者、发布 v2.0 可视化版本 |

### 3. 定策略

- **产品**：坚持「最小可用 + 可解释」，拒绝为炫技引入依赖。
- **治理**：Issue 模板、CONTRIBUTING、语义化版本、CHANGELOG，形成可复制的协作范式。
- **社区**：主动在相关仓库提交有价值的 Issue，写中文教程引流。
- **风险**：防止退化为「作业仓库」——固定节奏发版、及时回复 Issue；
  供应链风险——坚持零第三方依赖。

## 三、结论

MiniChain 的商业价值有限，但作为**教学基础设施**具有清晰的战略位置：
以极低的维护成本占据「区块链第一课」的心智入口，再通过文档与课程渠道形成复利。
